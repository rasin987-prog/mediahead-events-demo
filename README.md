# Mediahead Events — демо шаблона сайта театра

Собранный прототип универсального шаблона сайта театра. Девять страниц,
три переключаемые визуальные темы, демо-контент вымышленного «Городского
драматического театра».

Переключатель тем — в шапке справа: `Академический`, `Независимый`, `Камерный`.

Этот репозиторий содержит только результат сборки и обновляется автоматически.
Исходники, сборщик и тесты живут в отдельном репозитории.
